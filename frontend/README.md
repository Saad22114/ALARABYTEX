# القماش العربي - Frontend

نظام إدارة أعمال الأقمشة — واجهة أمامية مبنية بـ Next.js 14

## التشغيل

```bash
npm install
npm run dev
```

التطبيق يعمل على: http://localhost:3000

## متطلبات

- Node.js 18+
- Backend يعمل على http://127.0.0.1:8000

## متغيرات البيئة

انسخ `.env.example` إلى `.env.local` وعدّل حسب الحاجة:

```
NEXT_PUBLIC_API_URL=http://127.0.0.1:8000/api
```
